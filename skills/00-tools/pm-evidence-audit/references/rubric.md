# 证据判定规则

先按“主张具体表述、指标口径、时间、地区、人群、直接支持程度”核对，再选**一个主状态**。必要时在“依据和局限”说明次要风险。状态不是概率或法律/财务保证。

| 状态常量 | 判定条件 | 报告中要写明 |
|---|---|---|
| `VERIFIED` | 可访问的原始证据直接支持该主张的关键范围、口径和日期 | 原始来源、相关位置、时间与仍存在的局限 |
| `UNVERIFIED` | 无来源、来源不可访问、仅有转述或数据不能支持该表述 | 缺失了什么，最小补证据动作；无来源时必须是 UNVERIFIED |
| `CONFLICTED` | 两个或多个可信来源相互矛盾且差异未解释 | 双方来源、口径和日期、可能的冲突原因；相互矛盾时不能择一报 VERIFIED |
| `OUTDATED` | 主张依赖时效，而所给来源已不能代表所声称的时期 | 原始日期、为何过期、需要何时的新证据 |
| `INFERENCE` | 结论由事实推导或预测而来，原始材料未直接观测该结论 | 已证实的前提、推理步骤、反例及需要验证的假设 |

## 使用顺序

1. 首先检查是否找得到可访问的证据。**来源存在不等于来源支持主张**；来源只能支持较窄结论时，对原主张标记 `UNVERIFIED` 或 `INFERENCE`，并建议降级措辞。
2. 若证据相互矛盾，主状态优先用 `CONFLICTED` 并并列来源；不能藏掉不利证据。
3. 对时间敏感的主张，来源与所称时间不匹配时用 `OUTDATED`；是否“过期”由该主张的变化速度决定，不写死月数。
4. 原始事实与推断分开。`INFERENCE` 不等于错误，但不得呈现为直接测得的事实。
5. `VERIFIED` 只表示在已检查范围内有直接支持，**不等于绝对真实**。无法打开全文、未核对原始表格或样本偏差仍须在局限中说明。

## 来源优先顺序

优先核查一手材料（官方原文、原始数据、实际访谈记录、实验结果）；其次为可信的独立复核；媒体转述与搜索摘要只能作为线索，不能替代原始证据。对双方存在利益关系的材料标注来源背景。用户禁止联网时，不用外部搜索；只核对用户提供的证据，并将无法外部复核的部分如实标为未验证。
