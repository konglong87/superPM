# 产物写入边界

适用于 Super-PM 的所有技能。默认响应是聊天建议；仅在用户明确要求生成/更新文件时才开始写入流程。Preamble 只能读取和说明状态，不得创建目录、草稿、缓存或报告。

1. 写入前确定**当前产品/项目**、精确文件路径及目标产物类型。相似文件名不等于当前产品的证据；先检查内容相关性。
2. 目标已存在时，先说明覆盖、追加或创建副本的差别，取得用户选择；不能无声覆盖。用户只讨论时不创建目录或文件。
3. 确认后，紧贴实际 `Write` 操作创建该输出文件的父目录。不要为了可能的未来步骤预创建所有阶段目录。
4. 写完只报告实际生成的文件和已验证内容；跳过的步骤、未保存的草稿和未核实的来源不得标记完成。
5. 单独安装技能时也须保留其自身的最小写入边界，不依赖本共享文件才能安全执行。

后续若要支持同一仓库内多个产品，请单独设计产品命名空间和旧路径兼容；本规则只防止启动时副作用与无声覆盖，不宣称已解决固定文件名冲突。
