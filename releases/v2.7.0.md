# super-pm v2.7.0 — 2026-09-27

从上一个公开 tag `v2.6.1` 以来，本次版本合并了技能包结构、流程门禁、文档预览安全与真实行为评测方面的改进。仓库在此期间曾标记 `2.6.2`，但没有公开 `v2.6.2` tag；本次创建的是全新的 `v2.7.0`，不移动旧 tag。

## 新增

- 六个可独立安装的工作流入口，以及带完整依赖安装命令的预检；单独安装入口不会假装完成缺失步骤。
- 独立的 `pm-evidence-audit` 技能，区分有来源、无来源与待验证的市场主张。
- 21 个 Agent 行为场景及自评/独立审阅区分；原始隔离会话、文件前后清单与定向回归记录可追溯。

## 修复与改进

- 新产品需求路由尊重头脑风暴门禁，显式跳过则直达相应流程；只讨论时不自动写文件。
- 无 Reach/Effort 数据时不再为 A/B/C 占位需求生成精确 RICE 分数。
- 文档预览改用本地渲染与净化依赖，补上路径和静态资源安全回归。
- 版本同步现在覆盖根包、Claude/Cursor 插件、marketplace 全部条目、六个模块插件与技能包说明。

## 验收边界

- 发布前运行 `npm test` 与技能包自检；版本号需要在所有 manifest 一致。
- 已完成六场景有/无 skill 隔离对照，失败项作了定向回归。评测结论仍为**当前 Agent 自评**，不是独立审阅通过；不要把静态测试当作模型行为验收。
- 纯文本/CLI 发布没有 UI 图片，截图不适用；以原始响应、文件清单、测试结果和远端 tag 指向为准。
